ABSTRACT

Cloud-Based Skill Credential and Digital Portfolio System

The increasing demand for verified technical qualifications has created a critical need for efficient, tamper-proof academic credential management and digital portfolio systems. Traditional credential verification methods provide limited visibility into authentic student competencies and make it difficult for employers and institutions to verify certificates without time-consuming manual correspondence. To address these challenges, this project proposes SkillVault, a Cloud-Based Skill Credential and Digital Portfolio System, designed to catalog academic credentials, automate metadata ingestion, enforce cryptographic authenticity, and provide interactive oral defense evaluation.

The proposed system utilizes a serverless static cloud architecture deployed on Amazon Web Services (AWS S3) in the ap-southeast-2 region. To overcome the recurring costs of cloud-hosted optical character recognition, the system executes Tesseract.js inside the browser’s WebAssembly runtime, extracting course titles, issuing bodies, recipient names, and dates on the client side at zero cloud operational expense.

Additionally, SkillVault integrates the W3C Web Crypto API to generate immutable SHA-256 cryptographic signatures and ledger block descriptors for every registered credential. When queried through the Public Verification Registry, real-time recalculation detects unauthorized alterations instantly. The platform also introduces an AI-powered Viva Exam module that generates subject-specific oral defense questions and utilizes speech synthesis, awarding a “Viva-Verified” badge upon passing (≥ 70%).

The proposed system demonstrates how cloud storage and edge computing can be combined to provide scalable, centralized, and mathematically verified credential management. SkillVault aims to eliminate resume fraud, reduce administrative verification overhead, and support students in building recruiter-ready portfolios.

CHAPTER 1: INTRODUCTION

1.1 Introduction

Digital credentials and technical certifications represent an essential component of modern education and hiring. Documenting verified competencies is necessary for demonstrating skills, improving career readiness, and distinguishing genuine talent from unverified claims. Traditional credential management methods often depend on physical certificates or static scanned PDF files. These methods may make it difficult for academic institutions and recruiters to detect altered documents, extract metadata quickly, and evaluate whether candidates genuinely understand the underlying course concepts.

SkillVault is developed to make credential management and skill validation more efficient by using the concepts of cloud computing and browser-based edge processing. It allows students to manage academic certificates, projects, and credentials through an integrated web-based platform.

The system extracts certificate information using client-side Optical Character Recognition (OCR) powered by WebAssembly, eliminating the recurring cost of cloud vision APIs. Extracted metadata is cryptographically sealed using SHA-256 digests and tied to cloud ledger blocks to ensure tamper-proofing.

The project also explores cloud computing through Amazon Web Services. Amazon S3 provides high-durability, serverless cloud storage for hosting the production static website, while client-side storage runtimes maintain credential records with sub-millisecond retrieval speeds.

1.2 Overview of the Project

SkillVault provides an integrated digital credential environment where users can:

  • Upload certificate images and PDFs with instant browser-based validation.
  • Automatically extract metadata (Title, Issuer, Recipient, Date) using in-browser WebAssembly OCR.
  • Generate immutable SHA-256 cryptographic fingerprints and ledger block descriptors.
  • Verify credential authenticity in real-time through a public recruiter verification portal.
  • Simulate data tampering interactively to observe cryptographic anti-tamper alerts.
  • Participate in AI-driven Viva oral examinations with real-time speech synthesis.
  • Earn "Viva-Verified" badges upon demonstrating subject matter mastery (≥ 70%).
  • Publish customizable, shareable public portfolio URLs for technical recruiters.
  • Host the complete web application serverlessly on Amazon Web Services S3.

CHAPTER 2: PROBLEM STATEMENT

Traditional credential management methods often require users to manually type certificate details and store unverified digital copies. These methods may not provide real-time verification or effective ways to prevent unauthorized tampering.

Some common problems include:

  • Difficulty verifying certificate authenticity in real time without contacting issuing bodies.
  • Vulnerability of digital certificates to image manipulation and forged recipient names.
  • Manual data entry fatigue when students upload multiple course credentials.
  • Prohibitive API billing costs associated with cloud-hosted OCR services like AWS Textract.
  • Lack of mechanisms to test whether a certificate holder genuinely learned the subject.
  • Lack of proper centralized portfolio presentation for recruiters and academic evaluators.

Therefore, there is a need for a smart credential verification system that automates metadata ingestion, ensures tamper-proof authenticity, and supports interactive competency evaluation.

SkillVault addresses these problems by combining client-side edge computing with cloud storage to ingest, protect, and verify credential data.

CHAPTER 4: EXISTING SYSTEM

4.1 Existing System

Traditional credential verification systems generally depend on manual inspection of paper certificates or static PDF uploads on generic file-sharing platforms. Users must manually type certificate metadata to catalog their credentials.

Some enterprise verification platforms provide centralized validation, but they typically require subscription fees, centralized backend servers, and expensive cloud OCR infrastructure that increases operational costs.

4.2 Limitations of the Existing System

  • Manual data entry takes time and causes typographical errors.
  • Real-time verification facilities are limited or require third-party intervention.
  • Static PDFs can be easily altered using image-editing software.
  • Cloud OCR solutions incur recurring per-page transaction fees.
  • Certificates do not reflect whether the holder actively mastered the subject.
  • Hosting complex backend servers increases deployment and maintenance costs.

CHAPTER 5: PROPOSED SYSTEM

5.1 Proposed System

SkillVault is proposed as a cloud-based credential verification and digital portfolio system that simplifies the ingestion, storage, and validation of academic achievements.

The system extracts text from certificate files using Tesseract.js inside browser WebAssembly and populates form fields automatically. The application canonicalizes certificate data and computes a 256-bit SHA-256 cryptographic digest tied to an immutable ledger block descriptor.

The platform is hosted on Amazon S3 static website hosting, providing global accessibility with zero server management. Users can share public portfolio links, test authentic oral defense questioning, and verify credentials against the cloud ledger in real time.

5.2 Main Modules

1. Edge OCR Ingestion Module

This module uses Tesseract.js inside a background Web Worker to parse uploaded certificate files locally and extract Title, Issuer, Recipient, and Date without cloud costs.

2. Cryptographic Hashing Module

4

This module canonicalizes certificate metadata and computes standard SHA-256 digests using the W3C Web Crypto API, binding the record to a unique ledger identifier (e.g. BLK-100234-749C5747).

3. Real-Time Verification Module

This module enables recruiters to enter Credential IDs to verify metadata against the ledger. Any tampering triggers an immediate cryptographic mismatch alert.

4. Cloud Object Storage Module

Amazon S3 is used to host static web assets and distribute production bundles globally with high durability and availability.

5. AI Viva Defense Module

This module generates subject-specific viva questions, grades candidate responses in real time, and awards the "Viva-Verified" credential badge upon scoring ≥ 70%.

6. Tamper Simulation Module

This module allows evaluators to simulate data tampering by modifying letters in student names to demonstrate the real-time cryptographic integrity guard.

7. Public Portfolio Showcase Module

This module generates shareable portfolio URLs with category filters (Courses, Badges, Projects) and direct verification links for recruiters.

8. Dashboard Module

The dashboard provides an overview of credential metrics, verified badges, OCR scanning records, and role-readiness indicators.

CHAPTER 7: CLOUD COMPUTING CONCEPTS

7.1 Cloud Computing

Cloud computing is the delivery of computing resources such as servers, storage, databases, and networking services over the internet.

Instead of purchasing and maintaining physical servers, users can access computing resources from cloud service providers whenever required.

Cloud computing provides flexibility, scalability, availability, and cost efficiency.

In SkillVault, cloud computing concepts are explored through Amazon Web Services (AWS). AWS S3 is used for serverless static website hosting and global asset distribution.

7.2 Cloud Service Models

Cloud computing is commonly classified into three service models.

Infrastructure as a Service (IaaS)

IaaS provides virtualized computing infrastructure over the internet. Users can access virtual machines, raw storage, and networking resources without purchasing physical hardware.

Platform as a Service (PaaS)

PaaS provides a platform and environment for developing, running, and managing applications without requiring users to manage the underlying infrastructure.

Software as a Service (SaaS) / Storage as a Service

SaaS provides ready-to-use software applications over the internet accessible through web browsers. Amazon S3 static hosting exemplifies Storage-as-a-Service, delivering web applications without server management.

7.3 Amazon Web Services (AWS)

Amazon Web Services is a comprehensive cloud computing platform that provides services for computing, storage, networking, databases, security, and application deployment.

AWS allows developers and organizations to build and manage applications using scalable, on-demand cloud resources.

7

Some important AWS services include:

  • Amazon S3: Provides scalable object storage and static website hosting.
  • Amazon CloudFront: Delivers low-latency global content delivery (CDN).
  • Amazon EC2: Provides resizable virtual computing servers.
  • AWS Lambda: Executes serverless code in response to system events.
  • AWS IAM: Manages users, security roles, permissions, and access policies.
  • Amazon DynamoDB: Provides managed serverless NoSQL database services.
  • Amazon CloudWatch: Monitors cloud resources and application metrics.

7.4 Amazon S3

Amazon Simple Storage Service (S3) is an object storage service offering industry-leading scalability, data availability, security, and performance.

S3 stores data as objects within buckets. It is designed for 99.999999999% (11 9's) of durability and offers flexible static website hosting capabilities.

Important features of Amazon S3 include:

  • Bucket creation and regional data residency.
  • Static website hosting with configurable index and error documents.
  • Granular access control using Bucket Policies and Access Control Lists.
  • High data durability through automated replication across Availability Zones.
  • Pay-as-you-go pricing with zero idle server running costs.

7.5 Important S3 Concepts

Bucket

A bucket is a container for objects stored in Amazon S3. In this project, bucket 04112026 is provisioned to host the SkillVault web application.

Object

An object consists of file data and metadata. Static files (index.html, JavaScript, CSS, and SVG icons) are stored as objects in S3.

Bucket Policy

8

A bucket policy is a JSON-based access policy used to grant permissions to S3 resources. A public read policy allows internet users to access hosted website assets.

Region

A region is a geographical area where AWS operates its cloud infrastructure. Bucket 04112026 is hosted in the Asia Pacific (Sydney) region (ap-southeast-2).

Availability Zone

An Availability Zone is an isolated location within an AWS region. S3 automatically replicates data across multiple Availability Zones to ensure high availability.

7.6 Other Cloud & Web Concepts Used in SkillVault

Client-Side Edge Computing

Edge computing offloads compute-heavy workloads to user devices. By executing OCR and cryptographic hashing in the browser, SkillVault reduces cloud compute costs and eliminates server bottlenecks.

WebAssembly (WASM)

WebAssembly provides a secure, sandboxed execution environment in web browsers running compiled code at near-native speeds. It allows Tesseract to perform neural OCR without cloud servers.

Cryptographic SHA-256 Hashing

SHA-256 converts arbitrary data into a fixed 256-bit hash. Any alteration in the input data dramatically changes the digest, providing mathematical proof of document integrity.

Web Workers

Web Workers execute JavaScript on background threads, allowing heavy image processing and OCR execution to proceed without freezing the user interface.

CHAPTER 9: SYSTEM IMPLEMENTATION

9.1 Frontend Implementation

The frontend of SkillVault is developed using React.js and Vite. It provides the user interface through which users interact with the credential vault, portfolio views, and verification tools.

React components structure the application into distinct views: Dashboard, Credential Management, Public Portfolio, Verification Portal, and Viva Exam Modals.

9.2 Client-Side OCR Implementation

The application integrates Tesseract.js inside a background Web Worker. When a user uploads a certificate image or PDF, the worker extracts raw text, filters OCR noise, and uses regular expression patterns to auto-fill course titles, universities, recipient names, and dates.

9.3 Cryptographic Integrity Implementation

The cryptographic integrity module normalizes metadata fields into a canonical JSON string. It uses crypto.subtle.digest('SHA-256') to compute a 64-character hash. The record is assigned a simulated cloud ledger block ID (e.g. BLK-100234-749C5747).

When queried, the verification portal recalculates the hash of current fields in real time and compares it with the stored ledger hash to detect unauthorized tampering.

9.4 AI Viva Exam Implementation

The viva module dynamically parses the course domain and generates multiple-choice questions. It provides interactive option selection, score calculation, and speech synthesis audio output using the Web Speech API. Scoring ≥ 70% upgrades the credential to “Viva-Verified”.

9.5 Cloud Deployment Implementation

12

The application is compiled into static production chunks using Vite. The resulting files in the dist/ directory (index.html, JavaScript, CSS, and SVG assets) are uploaded to the AWS S3 bucket 04112026. S3 static website hosting serves the application over standard web protocols.

9.6 Integration of Components

The React frontend, WebAssembly OCR engine, Web Crypto hashing module, and AWS S3 static hosting work together to provide a complete credential verification platform.

When a user uploads a certificate, the Web Worker extracts the metadata. The cryptographic engine signs the payload and stores the record in client persistence.

When an evaluator queries a Credential ID through the public verification portal, the engine performs a real-time integrity check, guaranteeing that credentials have not been tampered with.

This integration allows students to manage credentials, recruiters to verify documents, and examiners to conduct oral defense evaluations through a unified cloud platform.

CHAPTER 10: ADVANTAGES AND LIMITATIONS

10.1 Advantages

  1. Automates certificate metadata extraction using client-side WebAssembly OCR.
  2. Eliminates cloud vision API costs by executing text recognition inside user browsers.
  3. Guarantees credential authenticity using standard SHA-256 cryptographic hashing.
  4. Provides instant detection of unauthorized document tampering through real-time checks.
  5. Includes an interactive tamper simulation mode for demonstration and evaluation.
  6. Introduces an AI Viva oral exam module testing domain competence beyond paper credentials.
  7. Hosted serverlessly on AWS S3 with zero virtual machine maintenance overhead.
  8. Demonstrates the practical integration of cloud storage, edge computing, and cryptography.

10.2 Limitations

  1. OCR accuracy depends on certificate image resolution, contrast, and layout complexity.
  2. WebAssembly OCR processing speed varies based on client CPU performance.
  3. Internet connectivity is required to access the hosted application from AWS S3.
  4. The simulated ledger operates on browser-native cryptography rather than a decentralized public blockchain.
  5. The Viva question engine currently uses pre-configured domain banks rather than dynamic live LLM streaming.
  6. Client-side IndexedDB persistence requires browser data to remain intact unless cloud database synchronization is enabled.

CHAPTER 11: FUTURE ENHANCEMENTS

SkillVault can be improved further by introducing additional features.

  1. Amazon CloudFront Integration: Configure an AWS CloudFront CDN distribution for edge caching and custom domain SSL/TLS termination.
  2. Serverless Database Integration: Connect AWS Lambda and Amazon DynamoDB for real-time cloud synchronization across multiple student accounts.
  3. Public Blockchain Anchoring: Anchor generated SHA-256 digests onto a public blockchain (such as Polygon or Ethereum) for universal non-repudiation.
  4. Dynamic Generative AI Viva: Integrate Amazon Bedrock or cloud language models to generate fully dynamic viva questions based on custom course syllabi.
  5. Automated CI/CD Pipeline: Implement GitHub Actions to build and deploy production assets to AWS S3 automatically on master branch commits.
  6. Mobile Application: Develop a dedicated mobile app supporting offline credential access and mobile camera OCR scanning.
  7. Institutional Issuer Portals: Provide accredited universities and certification providers with bulk cryptographic signing tools.

CHAPTER 12: CONCLUSION

SkillVault is a cloud-based credential verification and digital portfolio system developed to simplify the management and verification of academic credentials through cloud computing and edge offloading.

The system extracts certificate metadata using in-browser WebAssembly OCR, cryptographically seals records with SHA-256 digital signatures, and provides real-time verification against an immutable ledger block descriptor. It also features an AI Viva Exam oral defense module that confirms authentic subject mastery.

By integrating React.js, Vite, WebAssembly, Web Crypto, and Amazon Web Services S3, the project demonstrates how modern technologies can be combined to build a cost-effective, serverless web system.

The project explores essential cloud computing principles including Storage-as-a-Service, static hosting, edge computing, and cryptographic trust. Overall, SkillVault demonstrates the practical application of cloud computing in developing a secure digital credential system.
